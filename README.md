# Coding Theory Algorithms

Python library implementing different codes and related algorithms able to solve 
typical textbook exercises in Aarhus University's ['Information Theory and Coding'](http://kursuskatalog.au.dk/en/course/60135) course.

Features included:

* Linear Block Codes
* Cyclic Codes
* BCH codes
* Reed Solomon codes
* Galois Fields
* Binary Symmetric Channel

## Usage

See [playground.py](playground.py) for an implementation of the following two examples. 
Run with `python3 playground.py`.
Please refer to the code comments for a detailed function description.

Implementations live in `coding_theory_algorithms/`, for example
`from coding_theory_algorithms import GaloisField, CyclicCode`.
The package exports `BSC`, `GaloisField`, `GF2`, `LinearBlockCode`, `CyclicCode`,
`BCHCode`, and `RSCode`. Utility functions are available in their submodules.
Descriptive methods use snake_case; lecture notation includes `c()`, `s()`,
`G()`, `H()`, and `PU()`.

## Development

With [uv](https://docs.astral.sh/uv/) and Make installed, run these commands from the
repository root:

```sh
uv sync --locked
uv run python playground.py
make check
```

`make check` runs lint, formatting checks, and tests without changing source files.
Use `make test`, `make lint`, or `make format-check` to run individual checks.
`make format` applies formatting changes. `make compatibility` checks the local
Python matrix; see [compatibility instructions](docs/local-checks.md) for setup.

Python 3.10 or newer is required. Dependencies are recorded in `uv.lock`;
`uv sync --locked` installs them into the repository's `.venv`. Run commands
from the repository root; the project is not installed as a distribution.

g(X) = 1 + X2 + X3 + X4.

(a) Find the code rate, the generator and parity check matrices of the code in systematic form, and its Hamming distance.
(b) If all the information symbols are ‘1’s, what is the corresponding code vector?
(c) Find the syndrome corresponding to an error in the first information symbol, and show that the code is capable of correcting this error.

```

cc = CyclicCode(g, 7)
cc.print_info()
```
